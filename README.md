Swiggy Restaurant Data Analysis (EDA)

📌 Project Overview
This project performs Exploratory Data Analysis (EDA) on Swiggy restaurant data to uncover insights related to pricing, ratings, delivery time, and customer preferences.
The objective is to understand how factors such as location, cost, and ratings influence restaurant performance.

🎯 Objectives
Perform data cleaning and preprocessing
Analyze ratings, pricing, and delivery trends
Identify popular cities and restaurant distribution
Study relationships between price, ratings, and delivery time
Generate meaningful insights for decision-making

🛠️ Tools & Technologies
Python
Pandas, NumPy
Matplotlib, Seaborn
Jupyter Notebook

🔍 Analysis Performed
Data cleaning and handling missing values
Distribution analysis of ratings and cost
City-wise restaurant analysis
Delivery time analysis across different locations
Correlation analysis between variables
Relationship analysis between price and ratings

📊 Key Insights
Delivery time varies across different cities and areas
Mid-range priced restaurants tend to have higher ratings
Some cities have a higher concentration of restaurants
Ratings are distributed within a specific range
Pricing and ratings show correlation patterns
